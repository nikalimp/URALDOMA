## 4. Карта страниц
Одна страница — один кластер или один вопрос. Колонка «Прямой ответ» — черновик первого абзаца: агент развернёт его при сборке, но смысл и факты фиксируются здесь.

| URL | Тип | H1 | Кластер / главный запрос | GEO-запросы (№ из пула) | Прямой ответ (черновик) | Schema | Приоритет |
|---|---|---|---|---|---|---|---|
| `/` | Главная | | | | | WebSite, Organization, FAQPage | P0 |
| `/uslugi/` | Список услуг | | | | | ItemList | P0 |
| `/uslugi/<slug>/` | Услуга | | | | | Service, FAQPage | P0 |
| `/o-kompanii/` | О компании | | бренд | | | AboutPage, Person | P0 |
| `/kontakty/` | Контакты | | бренд + город | | | ContactPage | P0 |
| `/blog/<slug>/` | Статья | | | | | BlogPosting | P1 |
| `/politika-konfidencialnosti/` | Политика ПДн | — | — | — | — | — | P0 |

P0 — к запуску, P1 — в первый месяц после запуска, P2 — бэклог.

Серийные страницы (глоссарий, города, теги, справки) — отдельной строкой с количеством и планом наполнения: сколько страниц, кто пишет текст, сколько в неделю. Индексируются все; у каждой — поле расшифровки для title (полная форма аббревиатуры или русское название), чтобы title был 40–65 символов. **Любая страница из карты — от 250 слов основного текста к запуску**: в плане контента для каждого типа страницы заранее перечислите блоки, которыми набирается объём — определение, история, как работает, применение, рекомендации, частый вопрос, пример (стандарт §2, п. 8).
