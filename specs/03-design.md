## 3.1 Швейцарская типографика — принцип вёрстки
Решение Ника 2026-10-15: вёрстка сайта по принципам швейцарского (интернационального типографского) стиля. Конспект источников и как это применяем.

### Что это
Направление модернизма, сложившееся в Швейцарии в 1920–1950-х на идеях Баухауса («форма следует за функцией»), De Stijl, конструктивизма и «Новой типографики» Яна Чихольда (1928). Расцвет — 1950–60-е: Йозеф Мюллер-Брокманн, Армин Хофман, Эмиль Рудер, журнал Neue Grafik (1958–1965). Шрифты-символы — Akzidenz-Grotesk, Helvetica (1957), Univers, позже Frutiger. Дизайнер — ремесленник, а не художник: задача — ясно передать информацию.

### Принципы (по Skillbox Media и UPROCK)
1. **Модульная сетка.** Все элементы стоят на математически выстроенной сетке; размеры кратны модулю. Сетка даёт единые правила выравнивания, ускоряет вёрстку новых блоков и упрощает чтение: заголовки на одной направляющей.
2. **Асимметрия.** Композиция ведёт взгляд от главного к второстепенному; у каждого элемента — причина стоять там, где стоит, иначе он шум. Асимметрией выделяем элементы конверсии (CTA).
3. **Гротеск и минимум шрифтов.** Один шрифт, акценты — размером и начертанием, а не новыми гарнитурами. Флаговый набор — выключка влево, правый край рваный.
4. **Типографическая иерархия.** Сначала главное: крупный смелый заголовок, затем подзаголовок, текст. Контраст размеров создаёт динамику; типографика сама может быть главным изображением.
5. **Белое пространство.** Воздух — часть композиции, а не пустота: снимает напряжение и фокусирует.
6. **Фотография вместо иллюстраций.** Фото объективнее и вызывает доверие; иллюстрации — только простые геометрические.
7. **Цвет — наименее важен.** Монохромная основа и один акцент.
8. **Простые формы.** Прямоугольник — доверие и порядок; круг — завершённость (только маркеры).
9. **Объективность и ясность.** Убираем декор; остаётся только то, у чего есть функция.

### Как применяем в URALDOMA
| Правило | Реализация |
|---|---|
| Сетка | 12 колонок, контейнер 1440 px, поля 48 px (мобильный 16 px), gutter 24 px; базовый вертикальный модуль 8 px; секции — 128 px сверху и снизу (мобильный 64). В Tailwind: `grid-cols-12 gap-x-6`, отступы кратны 8 |
| Асимметрия | Заголовок секции — колонки 1–4 (или 1–6), содержание — 6–12 (или 7–12); фото 5 колонок + текст 6. Никаких центрированных блоков, кроме логотипа в шапке |
| Шрифт | Onest — всё; JetBrains Mono — только технические подписи. Выключка влево везде |
| Иерархия | H1 92 / H2 52 / H3 26–28 / текст 18 / подпись 12–14 (моно). Вес 500 для заголовков, 400 для текста |
| Нумерация разделов | «01 — Полный цикл», «02 — Услуги»… — моно-капс над H2; помогает навигации и задаёт ритм |
| Линейки | 1 px: сплошная #1F1B16 сверху списков и таблиц, 15 % — между строками. Списки услуг, тарифов, FAQ — таблицами с линейками, а не карточками |
| Цвет | Монохром кремовый / тёмный / коричневый + один акцент терракота #94532F (стрелки, номера, CTA). Бежевый — фон чередующихся секций |
| Формы | Радиус 0: кнопки и фото прямоугольные |
| Фото | Только реальные объекты, без рамок и теней, с моно-подписью «ЖК … · комната» |
| Процесс | «Чертёж»: аксонометрия квартиры собирается по стадиям, рядом таблица стадий с прогрессом и спецификацией (референс — 21st.dev Engineering Services, «exploded assembly scroll»: Inter Tight + JetBrains Mono, линейный чертёж, стадии 01–04, проценты и галочки) |

### Чего избегаем
Перегруза элементами и декором; более одного гротеска; центрированного текста; «кричащих» цветов; теней, градиентов (кроме затемнения видео для читаемости), скруглённых карточек; иллюстраций там, где нужна достоверность; хаотичной композиции вне сетки.

## 5. Стиль v3 — светлая классика + тёмная тема (решение Ника 2026-10-15, после запуска)

Причина: вёрстка v2 («Тёплый дом», кремовый фон, моно-метки, терракота) после запуска выглядела тяжело. Ник попросил вернуться к светлому классическому оформлению и добавить тёмную тему.

**Референсы:** [PAMM museum](https://www.behance.net/gallery/189082335/PAMM-museum) · [Solid Stone Creations](https://www.behance.net/gallery/185016135/Solid-Stone-Creations) · [Broadway Malyan](https://www.behance.net/gallery/139120523/Broadway-Malyan-Web-concept).

**Общий стиль трёх кейсов:**
- монохром: почти белый фон, почти чёрный текст, серый для второстепенного; цвет даёт только фотография;
- нейтральный гротеск, крупные заголовки обычным начертанием (не жирным), плотный трекинг; заголовок в два тона — чёрный + серый (PAMM);
- строка метаданных мелким кеглем по колонкам над/под главным заголовком (подпись серым, значение чёрным);
- волосяные линии 1 px, метки разделов «Название ——— (01)», счётчики-индексы у заголовков («Портфолио¹⁰»);
- пилюли: теги с обводкой и скруглёнными кнопками (Broadway Malyan), карточки и фото — без скруглений;
- инверсные чёрные блоки для акцентных разделов и футера; технический чертёж с размерными линиями (Solid Stone) — наш блок процесса.

**Что внедрено:**
| Было (v2) | Стало (v3) |
|---|---|
| кремовый фон #F4EFE6, терракота #94532F | фон #F6F6F3, текст #121212, серый #6B6B68, панели #ECECE8; акцент — бронза #8A5A3C только в номерах и стрелках |
| тёмной темы нет | `.dark`: фон #0F0F0E, текст #EFEFEB, серый #9B9B96, бронза #D49E7A; по умолчанию — системная тема, переключатель в шапке (луна/солнце) и в футере (Как в системе · Светлая · Тёмная), выбор в localStorage, без мигания (скрипт в `<head>`) |
| видео на весь первый экран, белый текст поверх | светлый первый экран: строка метаданных, двухтоновый H1 до 136 px, теги-пилюли, видео в рамке 16:10, форма справа |
| моно-метки капсом «01 — Услуги» | гротеск 13 px «Услуги ——— (02)»; моно осталось только на чертеже |
| Onest Medium в заголовках | Onest Regular, трекинг −0,035…−0,05 em |
| прямоугольные кнопки | кнопки и теги — пилюли; карточки, фото, таблицы — прямые углы |
| коричневые тёмные секции | инверсные блоки `--inverse` (#121212 / #1C1C1B в тёмной теме): процесс-чертёж, CTA, футер с крупным телефоном |

Токены — `src/app/globals.css`; переключатель — `src/components/theme-toggle.tsx`.

## 7. v5 «Журнал»: глянец, фото, авторский стиль (решение Ника 2026-10-15)

Ник: «в тёмной и светлой теме в некоторых местах не происходит смена цвета, многие элементы не совпадают с направляющими… меньше текста, больше фотографий… глянцевым как стильный журнал… современность, технологичность, элементы из 21dev».

### Найденные ошибки и исправления
| Ошибка | Как нашли | Исправление |
|---|---|---|
| Футер, заявка, чертёж, итог калькулятора, карточки на них оставались тёмными в обеих темах (токены `--inverse`) | сравнение цветов каждого элемента в светлой и тёмной теме (Playwright, 44 страницы) | токены `--panel-*`: светлая панель в светлой теме, тёмная — в тёмной |
| Заливки и линии чертежа зашиты светлыми (`rgba(230,230,225)`, `#d9d9d4`) — в светлой теме почти не видны | то же | `currentColor` + `fill-opacity` от цвета темы |
| Цвет панели браузера (`theme-color`) брался из системной темы, а не из выбранной | ручная проверка | один тег `theme-color`, его меняют скрипт темы и переключатель |
| Переключатель в футере не видел смену темы кнопкой в шапке | ручная проверка | общее событие `uraldoma:theme` |
| Зазоры 24 px (`gap-6`) вместо 20 px, сетки на 5 колонок, «ящики» с общими рамками без зазоров, чертёж на flex | замер краёв каждого блока против направляющих (Playwright) | только `gap-x-5`, число колонок делит 12, вместо рамок — линия сверху; чертёж — 7 + 5 колонок |

Правило вёрстки закреплено в `container.tsx`: любой ряд блоков — на 12-колоночной сетке, «ящики» без зазоров не используем.

### Фотографии
- 80 исходников клиента (`~/Desktop/URALDOMA/Objects`) обработаны заново: выравнивание вертикалей (поворот + трапеция по найденным вертикальным линиям, без растяжения деталей, снятых под намеренным углом), шумоподавление, тон (баланс белого, мягкая S-кривая, резкость). На обложке главной убраны бумаги и ключи с тумбы — ретушь только ровных поверхностей, без генерации.
- Экспорт: `NN.webp` 1440×1920 и `NN-720.webp`; для 24 кадров — широкие `NN-wide.webp` 1920×1080 и `-wide-960` для разворотов на весь экран (на телефоне — вертикальный кадр через `<picture>`).
- Подписи ко всем 80 кадрам — `src/content/photos.ts` (они же alt). Подписи описывают только то, что видно на фото.

### Стиль
- Типографика: гротеск Onest + курсив с засечками Playfair Display (локально, кириллица) для акцентных слов в заголовках, номеров и цитат — `<em>` в H1/H2.
- Фото вместо текста: обложка главной — фото на весь экран; услуги — карточки с фото; развороты объектов; лента «Детали»; страницы услуг, ЖК, статей — фото на весь экран под заголовком; объект — фотоистория по 12 колонкам с подписями «Fig. NN».
- Элементы в духе 21st.dev (без внешних библиотек): бегущая строка объектов, счётчики цифр, бегущий луч по рамке форм и выделенного тарифа, подсветка под курсором, точечная сетка у чертежа, лента с прокруткой по кадрам, смена темы «кругом» от кнопки (View Transitions), появление и параллакс фото на CSS scroll-driven animations.
- Всё движение выключается при `prefers-reduced-motion`; весь текст и итоговые цифры — в HTML сразу, анимация не прячет контент.
