## Что нельзя сделать без Ника
- Секреты GitHub `FTP_HOST`, `FTP_USER`, `FTP_PASS`, `FTP_DIR` = `www/uraldoma.ru/`. SSH-секреты можно оставить: когда порт откроют, выкладка пойдёт по SSH сама.
- `nikalimp/deploy-kit` → Settings → Actions → General → Access → «Accessible from repositories owned by the user», если ещё не включено. Через прокси сессии проверить нельзя.
- Id чатов Telegram и почты для заявок (T17), `lead-config.php` на сервере, просмотр `leads/*.csv`.
- Экспорт базовой линии из Метрики и Вебмастера.
- Слияние PR #5 (`design-swiss`) до PR с исправлениями. Иначе первая выкладка из `main` вернёт на сайт старый дизайн.
